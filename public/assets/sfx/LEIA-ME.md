# Sons próprios

Todos os sons do site são sintetizados no navegador. Para trocar um deles por uma gravação, ponha
aqui um arquivo com o nome do som e a extensão `.mp3`, `.ogg` ou `.wav`. Ele toca no lugar do
sintetizado, sem mexer no código.

| Arquivo | Quando toca |
|---|---|
| `blaster` | tiro de pistola, rifle e carabina blaster |
| `blaster-pesado` | armas pesadas (canhão blaster); a repetidora toca três `blaster` seguidos |
| `ion` | arma de íons |
| `lesma` | arma de projétil sólido |
| `bowcaster` | bowcaster |
| `flecha` | arco e funda |
| `sabre-ligar` | sabre ligando (botão Som) |
| `sabre-golpe` | golpe de sabre de luz |
| `sabre-choque` | sabre aparado ou bloqueado |
| `vibro` | vibrolâmina, vibromachado, lança de força |
| `soco` | ataque desarmado, bastão, clava |
| `garra` | garras e mordidas de feras |
| `arremesso` | faca, lança ou granada saindo da mão |
| `explosao` | granada e míssil chegando |
| `termal` | detonador termal |
| `missil` | lançador de mísseis |
| `chamas` | lança-chamas |
| `impacto` | tiro acertando, dano rolado |
| `grito` | o grito raro: 1 em cada 10 mortes de quem é de carne e osso |
| `morte` | queda de um combatente |
| `droide-morte` | dróide desligando |
| `rugido` | fera caindo |
| `forca` | poder da Força |

Use só gravações que você tem direito de usar (feitas por você, de bancos com licença livre, ou
compradas com licença). Os sons dos filmes, inclusive o grito famoso, são protegidos por direito
autoral e não vêm com o site: os sintetizados imitam o estilo sem copiar a gravação.
